Introduction

Platform Overview

What is CyberGuard?

CyberGuard is a browser-based, comprehensive cybersecurity analysis platform designed for security engineers, bug hunters, development teams, and system administrators.

It unifies multiple professional security tools under a single beautiful dashboard. Built as a full-stack SaaS application, it features a lightweight vanilla JavaScript frontend served by Vercel and a robust Laravel 12 backend with Docker scanner isolation.

Problem Statement

Pain Points
01

Fragmented Security Tools

Practitioners must manually install, configure, and switch between dozens of command-line tools (Nmap, SQLMap, ZAP), losing time and context.

02

High Technical Barriers

Command-line syntax, parameter tuning, and environment setups present a steep learning curve for developers, students, and system admins.

03

No Correlated Intel

Threat intelligence data is scattered. Analysts must visit separate websites (VirusTotal, Shodan, AbuseIPDB) to copy-paste and cross-examine indicators.

04

Manual Report Writing

Consolidating outputs, formatting tables, and compiling final client PDF deliverables is historically a manual, slow, error-prone task.

05

Lack of Collaboration

Traditional security CLI utilities are single-user only. Teams lack unified multi-tenant workspace environments with role-based access controls.

06

SSRF & Network Blockers

Executing queries and scans directly from the browser introduces strict CORS blockages and exposes corporate network IP geolocations.

Objectives & Scope

Deliverables

Core Goals & Accomplishments

  • Unify tools: Deliver a single web dashboard hosting network scanners, web securers, OSINT, JWT editors, and AI.
  • Live feeds: Implement asynchronous task queue and WebSockets for real-time log streaming.
  • Consolidated threat intel: Pull multi-API data in parallel with encrypted API key stores.
  • Auto-reporting: Implement client-side PDF/CSV generation engine.
  • Collaboration: Enable multi-user projects, organizations, and workspaces.

What is Out of Scope?

To maintain focus on core platform strengths, the following were designated out-of-scope for v1.0:

  • Native Mobile Applications (iOS/Android)
  • Self-hosted on-premises enterprise deployment packaging
  • CI/CD pipeline integrations (GitHub Actions, Jenkins)
  • Custom third-party scanner plugin API
  • Full automated phishing email dispatch management

FR: Auth & User Management

System Specs
FR-AUTH-001

Registration

Users register with name, email, job title, and password. Auto-triggers verification:

  • Queue-based email dispatch via Laravel job workers.
  • Mandatory verification link confirmation to activate login.
  • Strict password policies: min 8 chars, symbols, and numbers.
FR-AUTH-005

Token Login

Returns Laravel Sanctum Bearer tokens stored securely in client-side localStorage:

  • Tokens injected as Bearer Headers in Axios requests.
  • Brute-force protection: locks account after 5 failed attempts.
  • Session logs record login times and client IP ranges.
FR-AUTH-009

TOTP 2FA

Enables visual Google Authenticator compatibility. Generates secure QR codes:

  • Standard RFC 6238 TOTP algorithm implementation.
  • Generates inline SVG QR codes client-side.
  • Requires dynamic OTP verification before activation.

Dual Export Convention

To support in-browser vanilla global rendering while remaining fully testable under Node / Vitest environments, every single module file implements the dual-export pattern:

if (typeof module !== 'undefined' && module.exports) {
    module.exports = { APIClient };
} else {
    window.APIClient = APIClient;
}

Security & Infrastructure

Target Protection
01

CORS Bypasses

Uses server-side proxy overrides to prevent browser blocks when querying external targets:

  • Proxies requests via backend /api/proxy endpoints.
  • Strips restricting headers from remote target outputs.
  • Blocks open relay access by verifying API caller keys.
02

SSRF Protection

Checks and sanitizes target inputs before running scans to prevent injections:

  • Disallows loopback subnets and private IP ranges.
  • Sanitizes shell special chars (|, ;, &) in commands.
  • Resolves target host DNS addresses before active scan tasks.
03

Session Protection

Encrypts API keys, secures client storage items, and isolates sessions:

  • Stores Sanctum token using secure local settings.
  • Clears organization session scopes upon manual logouts.
  • Automatic user logouts triggered after 2 hours of inactivity.
